## Quickest Download Strategy

1. **Open 3 LEDVANCE product pages** (one per FL MAX wattage):
   - 1200W: productId=133998 (shows all 4 beam variants)
   - 900W: productId=133992
   - 600W: productId=133984

2. **On each page:**
   - Switch between "Show all versions (4)" to access each variant
   - Download LDT + IES for each beam angle
   - Download STEP 3D once (same for all)
   - Download Revit BIM once (same for all)
   - Download a product beauty JPG

3. **Total ~15 minutes** for all Floodlight MAX assets

4. Then repeat for FLEX 360W and 180W product pages
